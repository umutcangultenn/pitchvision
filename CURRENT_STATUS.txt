## ÇALIŞMAK İÇİN YAPILMASI GEREKENLER
================================================================================

1. BACKEND BAŞLATMA
   cd backend
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python -m uvicorn app.main:app --reload
   → http://localhost:8000
   → http://localhost:8000/docs  (Swagger UI)

2. DEMO KULLANICI OLUŞTUR (bir kez)
   cd backend
   python setup_demo_data.py
   → Email:    dev@pitchvision.local
   → Password: demo12345

3. FRONTEND BAŞLATMA
   cd frontend
   npm install
   # .env.local oluştur:
   echo NEXT_PUBLIC_API_URL=http://localhost:8000 > .env.local
   echo NEXT_PUBLIC_USE_MOCKS=false >> .env.local
   npm run dev
   → http://localhost:3000

4. STATSBOMB VERİSİ IMPORT ET (opsiyonel)
   cd backend
   python scripts/import_statsbomb_data.py --list-competitions
   python scripts/import_statsbomb_data.py --competition 11 --season 27 --team-id 1 --max 10
